# Debian 12 i386（32-bit / glibc / EHCI）での検証結果

## 検証環境

- 検証対象: `px4-userland` Stable v0.1.3 source archive
- ビルド生成物: `px4d` / `px4-ts` / `px4ctl`（ELF 32-bit Intel 80386）
- ビルド構成: PC/SC IFD無効のnative Release build（92/92 targets）、CTest 5/5合格
- ホストハードウェア: EPSON Endeavor NJ1000
- OS: Debian 12 i386（32-bit / glibc、EHCIコントローラ）
- 使用チューナー: PX-Q3U4 1台

## 検証結果

- ソースコードからのネイティブビルド（92/92 targets）および CTest（5/5）が成功した。
- PX-Q3U4 による8受信機同時の60秒gate試験および30分soak試験が合格した。
- 30分連続受信において、受信機0〜6は各約39億バイトを受信し、全TSエラー、キュー破棄、USBエラーはすべて0件であった。
- 受信機7のエラー発生状況は、同一試験個体で追跡中の既知バーストを再現した（TEI 10,988、continuity 614）。
- 内蔵カードリーダーに対する直接APDU送信試験は、30標本×10回の全試行が成功した。
- ステータス照会におけるUSBエラーおよびプロトコルエラーは0件であった。
- デーモンのファイルディスクリプタ数は29で固定され、RSSは安定推移した。
- 試験中のCPUおよび周辺温度は最高56℃であった。
- プロセス終了後にデーモンプロセスおよびエンドポイントの残留がないことを確認した。

## 適用範囲と境界

- 検証実績: 32-bit環境でのネイティブビルド、8系統同時受信、直接APDU通信。
- 検証対象外: PC/SC IFD（未ビルド・未検証）。

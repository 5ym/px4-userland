# px4-userland v0.2.1

Windows向けに、チューナー内蔵カードリーダーをB25対応アプリから利用するためのWinSCard互換DLLを追加しました。あわせて、Windowsでの起動処理とTSの連続性エラーの計数を修正しました。

## 主な変更
- Windows 11 x64向けに、アプリと同じフォルダーへ配置して使用するWinSCard.dllを追加
- 対応APIの範囲で、Windows標準の外付けカードリーダーとの併用に対応
- Windowsで、--runtime-dirを明示してもLOCALAPPDATAの状態によって起動に失敗する問題を修正
- TSの重複パケットと不連続指示の扱いを見直し、CCエラーの誤計数を修正

## 検証
- Linux・Android/Termux・macOS・Windowsの全9配布バイナリで、PX-Q3U4の短時間実機確認を実施
- Windowsの対象x64構成で、recisdb-rs、EDCB＋Multi2Dec／libaribb25、TVTest＋CasProcessor／TvCasによるTS復号を確認
- カード抜き差し、USB切断後の復帰、アプリの終了・再起動、外付けカードリーダーとの同時利用を確認。構成ごとの条件と確認範囲は[検証記録](https://github.com/Khronos31/px4-userland/blob/1a43b966f80cfd53c6306044415e43a5594d7954/docs/platforms/validation-results.md)を参照

## 既知の制限
- WinSCard.dllはx64・B25用途の限定APIに対応。x86／ネイティブARM64アプリや一般のWinSCard全APIは対象外。同じ版のpx4dを先に起動し、[導入手順](https://github.com/Khronos31/px4-userland/blob/4dbcf335a5d5b134ddc4a3ca29e4afb023ef91af/docs/platforms/windows-winscard.md)に従って配置すること
- PX-Q3U4のreceiver 7でTEI・CC不連続が発生する既知の制限は継続。今回の計数修正によって受信データの破損が解消したという意味ではない
- 非ASCII文字を含むパスで起動ログのready行が途切れる問題は継続。ASCII文字のみのruntimeパスを使うか、px4ctl statusで状態を確認すること（[Issue #52](https://github.com/Khronos31/px4-userland/issues/52)）
